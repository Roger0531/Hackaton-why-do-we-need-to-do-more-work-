# Hackaton-why-do-we-need-to-do-more-work-
Ми розробили сайт для надолуження матеріалу та закриття прогалин у знаннях з історії України, як частину підготовки до НМТ для учнів 10-11 класів.
Весь матеріал було отримано з підручника "ЗНО-НМТ 2027" Історія України від Тетяни Земерової.
![Головне зображення](source.jpg)
Продукт запускається через файл main.html через який йде подальша навігація по сайту.
